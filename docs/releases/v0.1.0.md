## OpenMeet v0.1.0 —— 首个公开版本

本地优先的 AI 会议助手：转录 · 识人 · 纪要 · 知识库，全部在你自己的电脑上完成。

### 下载

| 文件 | 平台 | 大小 | SHA256 |

安装包**自带 Python 运行时和全部依赖**，不需要预装 Python、CUDA 或 ffmpeg。安装到当前用户目录，不需要管理员权限。

> macOS / Linux 请暂时从源码运行，见 README。

### 安装须知

- **未签名**：首次运行会弹 Windows SmartScreen，点「更多信息 → 仍要运行」
- **GPU 加速**：安装包内置 CPU 版推理引擎。首次启动检测到 NVIDIA 显卡时，会在后台自动下载 GPU 加速组件（约 2.5GB，国内镜像），装完弹窗提示重启生效；期间可以正常以 CPU 模式使用。显卡驱动需 ≥ 570，**不需要**安装 CUDA Toolkit
- **模型**：首次使用在 设置 → ASR 模型 里一键下载（魔搭国内源，无需账号）。不知道选哪个看 [配置指南](https://github.com/FellforU/OpenMeet/blob/dev/docs/configuration-guide.md)
- 日志位置：`%LOCALAPPDATA%\com.openmeet.app\logs\`，反馈问题时请附上

### 功能

- 多引擎语音识别：faster-whisper / Qwen3-ASR / Paraformer 本地推理，OpenAI / 阿里云 API 可选
- 实时流式转写（麦克风 + 系统声音）
- 八道后处理：幻觉清理 → 数字规范化 → 口语清理 → LLM 纠错 → 分段 → 标点 → 说话人分离 → 声纹提取，进度实时可见
- 说话人分离（pyannote community-1）+ 声纹库跨会议识人，越用越准
- 结构化纪要（议题 / 结论 / 决策 / 待办）+ 思维导图 + XMind 导出
- 知识库 RAG：用自然语言向所有历史会议提问
- LLM 任选：Ollama 本地或 DeepSeek / 通义 / 智谱 / Kimi / OpenAI / Gemini 等 11 家
- 全局转录搜索、音频点击定位、项目文件夹管理、中英双语界面
